# ProcureAI

ProcureAI is a personal portfolio project exploring procurement workflows with SAP Integration Suite, SAPUI5/Fiori, a Node.js backend, MCP, and AI agents.

This repository brings the planned components together in a minimal monorepo-style structure. It currently contains documentation only: no business logic, applications, or dependencies have been added.

## Project folders

| Folder | Purpose |
| --- | --- |
| `docs/` | Project roadmap and future architecture documentation. |
| `mock-backend/` | Future Node.js backend using synthetic procurement data. |
| `fiori/` | Future SAPUI5/Fiori user interface. |
| `mcp-server/` | Future Model Context Protocol (MCP) server for AI tool access. |
| `integration-suite/` | Future documentation of the SAP Integration Suite work that already exists separately. |

## Getting started

Read the [roadmap](docs/roadmap.md) to see the planned phases. There is nothing to install or run yet.

## Demo data only

Use synthetic/demo data only. Never commit secrets, credentials, real SAP tenant URLs, company data, or personal tokens. Any future examples must use fictional values.
